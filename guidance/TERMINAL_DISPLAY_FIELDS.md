# 终端 2 显示字段解释

本文解释 `operator_console.py` 里看到的主要字段。终端 2 显示的是调试与操作信息，其中地形摩擦系数来自配置文件或后续动态地块状态，不等同于 Gazebo 每一帧求解出的真实接触力。

## CONTROL

当前控制状态和最近一次按键。

- `ACTIVE`：当前仍在持续发布非零运动指令。
- `IDLE` 或类似状态：当前没有有效运动输入，控制台会发布零速度。
- `command`：当前按键映射出的动作名称，例如前进、后退、原地左转。
- `last_key`：最近一次收到的键盘输入。

## TARGET

键盘输入希望小车达到的目标速度。

- `vx`：目标前进/后退线速度，单位 `m/s`。正数前进，负数后退。
- `wz`：目标偏航角速度，单位 `rad/s`。正负号表示左右旋转方向。

`TARGET` 是控制意图，不代表小车已经达到该速度。

## PUBLISHED

控制台实际发布到 `/cmd_vel` 的速度指令。

- 正常按键时一般和 `TARGET` 一致。
- 松手超过输入超时时间后会变成零速度。
- 如果 `PUBLISHED` 已经非零但小车不动，问题通常不在键盘输入，而在控制器、Gazebo 接口或接触物理。

## INPUT AGE

距离上一次有效按键输入过去了多久，单位秒。

如果这个值超过 `--input-timeout`，控制台会自动停车。

## ODOM

Gazebo 里程计返回的小车位置。

- `x`：世界坐标系下的前后位置，单位米。
- `y`：世界坐标系下的左右位置，单位米。
- `z`：高度，单位米。

当前 `/odom` 是 Gazebo 真值里程计口径，不是编码器、IMU、RTK 的融合里程计。

## VELOCITY

Gazebo 里程计返回的小车实际速度。

- `vx`：小车前后方向速度，单位 `m/s`。
- `vy`：小车横向速度，单位 `m/s`。
- `planar`：平面合速度，计算方式约为 `sqrt(vx^2 + vy^2)`。
- `wz`：实际偏航角速度，单位 `rad/s`。

调转向时重点看 `wz`；调直行时重点看 `vx` 和 `planar`。

## TERRAIN

控制台根据小车当前位置和 `examples/terrain_multi.yaml` 判断出的当前地块名称。

它反映的是“按配置推断小车在哪个地块上”，不是 Gazebo 接触求解器直接返回的结果。

## FRICTION

当前地块配置里的地面摩擦系数。

- `mu`：第一摩擦系数，通常可理解为主摩擦方向摩擦。值越大，地面越不容易打滑。
- `mu2`：第二摩擦系数，通常可理解为垂直于主摩擦方向的摩擦。对履带车横向滑移和转向手感很敏感。

简单记忆：

```text
mu/mu2 决定滑不滑
```

对履带车来说，`mu2` 太高可能导致横向擦滑困难，表现为左右转向吃力；`mu2` 太低可能导致车体横向漂移明显。

如果小车位于 `dynamic_pad`，终端 2 会优先显示 `/dynamic_friction/state` 中最近一次收到的 `mu/mu2`。如果还没有收到动态状态，则显示 YAML 中的默认值。

注意：`mu/mu2` 是最大抓地能力，不是简单的“数值越大车越慢”。想让速度差异更明显，通常应对比高附着和低附着，例如 `2.00 1.00` 与 `0.10 0.08`。

## CONTACT

当前地块配置里的接触参数。

- `kp`：接触刚度。值越大，地面越硬，小车越不容易陷入地面；过大可能导致接触抖动。
- `kd`：接触阻尼。用于抑制接触振荡；过小可能弹跳，过大可能显得发粘。
- `min_depth`：接触最小穿透深度，用于帮助 Gazebo 稳定判断接触。
- `max_vel`：接触修正最大速度，影响 Gazebo 把穿透物体推开的速度上限。

简单记忆：

```text
kp/kd 决定硬不硬、抖不抖
min_depth/max_vel 决定接触修正稳不稳
```

## TOPICS

当前控制台使用的 ROS2 话题。

- `cmd`：速度指令输出话题，当前主线为 `/cmd_vel`。
- `odom`：里程计输入话题，当前主线为 `/odom`。

## DRIVE

终端 2 当前采用的手动按键速度。

- `source=args`：速度来自启动参数，例如 `--linear-speed` 和 `--angular-speed`。
- `source=dynamic`：速度来自终端 3 发布的 `/dynamic_drive/set`。
- `linear_step`：按 `w/s` 时使用的线速度绝对值，单位 `m/s`。
- `angular_step`：按 `a/d` 时使用的角速度绝对值，单位 `rad/s`。

这组参数只改变人工键盘控制手感，不代表电机物理极限，也不应直接写成正式地形实验结果。

## DRIVE TOPIC

终端 2 监听动态速度指令的话题，默认是：

```text
/dynamic_drive/set
```

## LIMITS

控制台允许发布的速度上限。

- `linear`：最大线速度，单位 `m/s`。
- `angular`：最大角速度，单位 `rad/s`。

它们是手动操作台的限幅，不是电机物理极限，也不是正式地形实验速度。

## 地块摩擦和履带接触参数的区别

终端 2 当前展示的 `FRICTION` 是地块表面的配置摩擦系数。

机器人自身还有一组履带轮接触参数，位于：

```text
snowplow_sim/examples/robot_default.yaml
```

其中关键项包括：

```yaml
tracks:
  contact_mu1: 20.0
  contact_mu2: 0.35
  contact_slip1: 0.0
  contact_slip2: 0.35
```

区别如下：

- 地块 `mu/mu2`：描述地面材料，例如水泥、沙土、雪地、动态摩擦地块。
- 履带 `contact_mu1/contact_mu2/contact_slip*`：描述简化履带轮和地面接触时允许怎样抓地、怎样横向擦滑。

如果调试转向，通常先看履带 `contact_mu2/contact_slip2`；如果调试不同地面通过性，通常先看地块 `mu/mu2`。
